# Araç Kaydı (Doğrulanmış Ücretsiz Araçlar)

Her sınır resmî belgeden doğrulanmıştır. Doğrulanmamış hiçbir araç göreve atanmaz.

## Doğrulanmış ücretsiz araçlar

| Araç | Ücretsiz sınır | Kaynak |
|---|---|---|
| Cloudflare Workers | 100.000 istek/gün, 10 ms CPU | CF Workers limits |
| Cloudflare D1 | 5 GB, 5M okuma/gün, 100K yazma/gün | CF D1 pricing |
| Cloudflare Durable Objects | 100.000 istek/gün, 13.000 GB-s/gün | CF DO pricing |
| Cloudflare R2 | 10 GB, egress ücretsiz | CF R2 pricing |
| Cloudflare Pages | 500 build/ay, 20.000 dosya | CF Pages limits |
| Cloudflare Workflows | 3.000 adım/gün, 1 GB-ay | CF Workflows pricing |
| GitHub (public) | Actions standart runner ücretsiz | GitHub billing |

## Görsel varlık kaynakları (lisans doğrulanmış)

| Kaynak | Lisans | Atıf |
|---|---|---|
| Kenney.nl | CC0 (public domain) | Gerekmez |
| Game-icons.net | CC BY 3.0 | Zorunlu |
| Met Museum Open Access | CC0 | Gerekmez |
| Wikimedia Commons / OpenGameArt | CC0/CC BY karışık | Varlık başına |

Her varlık `assets/manifest.json` içinde kimlik + lisans + kaynak ile kayıtlıdır.
